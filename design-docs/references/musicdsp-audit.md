# MusicDSP source audit

## Scope and pin

Audited Effects and Filters entry inventory at [bdejong/musicdsp](https://github.com/bdejong/musicdsp/tree/d7c8525c9b3aa007b34caa682624f4e7a28c7264/source),
commit `d7c8525c9b3aa007b34caa682624f4e7a28c7264`, on 2026-09-30.
The checkout has no root LICENSE/COPYING grant. Each entry is considered separately.
The license column reports notices found in the entry, not a legal inference about
attachments or dependencies. Unspecified entries are research only. No archived
source, attachment, impulse recording or proprietary preset is copied into Vactr.

The selected additions are independent implementations using Vactr's existing
DSP primitives. Similarity of filter/effect families does not imply exact transfer
curve or circuit equivalence. Deferred entries are acknowledged distinct work,
not claimed implemented. Parametric resonator is an original requested extension;
there is no claim of an archive entry named “parametric resonator.”

## Additional primary research

- [Julius O. Smith, Elementary Filter Sections](https://www.dsprelated.com/freebooks/filters/Elementary_Filter_Sections.html): pole radius/angle, allpass and resonator foundations. Independent RT60 controls use radius exp(-ln(1000)/(sample-rate × decay)).
- [Gamper, Parker and Välimäki, spring reverb model calibration](https://www.dafx.de/paper-archive/2011/Papers/39_e.pdf): dispersive spring modeling; original implementation, no paper code copied.
- [DAFx 2008 spring dispersion modulation](https://dafx.de/paper-archive/2008/papers/dafx08_36.pdf): allpass dispersion model research.
- [Eventide Blackhole product description](https://www.eventideaudio.com/pedals/blackhole/) and [official algorithm manual](https://cdn.eventideaudio.com/manuals/h9/0.0.1/en/content/algorithms/reverb.html): user-visible spacious, swelling and freeze behavior only. `space-reverb` is an original algorithm, with no hardware parity claim.

Shimmer and tape/diffusion delay are requested original extensions. Shimmer's
pitch shifting belongs inside the recirculating path; adding a pitch shifter
after an existing reverb would not satisfy that structure. Spring, space and
shimmer are evaluated independently from the existing four-line FDN variants.
