The source page states **Free to use, royalty-free (CC0)** and describes its
synthesized kick, noise-and-tone snare, and noise hats. This is a synthetic
recreation of an Amen-style pattern, not the original Winstons recording.
Retrieved 2026-09-30. License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

`source.wav` retains the downloaded float32 stereo 44.1 kHz audio.
`provenance.json` records its source URL, checksum, format and provenance.
The complete source WAV is used directly. All chopping, rearrangement,
retriggering and reverse playback are defined in the `.vact` score using
`start-ms`, `stop-ms`, `chop`, `slice`, `splice`, and `speed`.
