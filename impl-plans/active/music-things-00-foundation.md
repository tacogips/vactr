## Intent and Context

This plan makes the root package a workspace and creates the three crates
`music-things-dsp`, `music-things-synth` and `music-things-fx`, holding
only the shared types. It then wires vactr to them through re-exports, the
two context traits and the kind mirror. After this plan, every later plan
only moves kernel and group files. It never touches manifests, `Cargo.lock`
or core types again.

Every crate dependency edge is declared now, including fx -> synth, so
`Cargo.lock` changes only in this plan.

## Non-goals

- Moving any kernel or effect-group file (MTX-S*/F* plans), except
  `effects/prim.rs` and `fft.rs`.
- Moving the kind dispatch (`params`/`mem_len`/`init`/`process`; MTX-90).
- Notices (MTX-91).
- Changing `mise.toml`, setting `default-members`, or adding features to
  the crates.
- Editing any existing test file. The only test changes are the new
  `fx_kind_map.rs` and its `mod` line.

## Dependencies

- dependsOn: none
- Blocks: MTX-S1, MTX-F1 (and transitively all)

## Pitfalls

- **Baseline order.** Capture the baseline list BEFORE editing. A list
  taken after the workspace conversion is invalid.
- **Banned tokens.** No `crate::` anywhere under `music-things/`, in
  comments too. Use `super::` (for example `use super::ParamDef;` in
  `param_set.rs`). The macro-free enum avoids `$crate`.
- **Variant renames.** Do not rename or reorder variants other than
  `StreamOpto`. `Hash` and `Debug` must match the vactr derive set.
- **`missing_docs` reach.** `missing_docs` covers enum variants, struct
  fields and trait methods.
- **Cargo.lock.** Do not run `cargo update`. If `Cargo.lock` shows any
  change beyond the three path packages, stop and record it.
- **No test edits.** `src/dsp/tests/dsp/*.rs` files build `Kx { … }` and
  `FxCtx { … }` by literal. Those structs must keep their exact fields.
- **Lifetimes in `fx_ctx`.** If borrowck complains about reborrowing
  `self.store` as `&dyn SampleSource`, write
  `samples: self.store as &dyn SampleSource`. Do not change `FxCtx`'s
  fields.

## Tests to add

- `NoSamples.sample(0)` -> `None`. A 6-float, 2-channel view -> `frames() == 3`.
- `PortValues::from_defaults(&[("freq", 440.0), ("amp", 0.5)])`:
  `inputs()[0].first() == 440.0` and `inputs()[1].first() == 0.5`. Index
  2 -> `Inp::Val(0.0)`. `set(60, 1.0)` is ignored.
  `set_buffer(0, &[1.0, 2.0])` -> `inputs()[0].at(1) == 2.0`.
- `ParamSet::new(&[ParamDef::new("drive", 0.5, 0.0, 1.0)])`:
  `values() == [0.5]`. `set(0, 2.0)` -> `1.0`. `set(0, f32::NAN)` ->
  `0.5`. `set(5, 1.0)` is ignored. `set_named("drive", 0.25)` -> `true`.
  `set_named("x", 1.0)` -> `false`.
- `fx_kind_map`: the two tests above.
